# SteamForge 2.0 (CyberForge Suite) 🎮⚡

Универсальный менеджер и генератор манифестов Steam (stplug-in), дополнений (DLC) и конфигурационных файлов для платформы Valve Steam.

## 🚀 Возможности
- **Два визуальных стиля**:
  - 🟢 **Matrix HUD**: анимированный фон с эффектом дождя глифов, моноширинный терминал, хакерский загрузчик.
  - 🔵 **Cyber Blue (Легаси)**: классический современный плоский интерфейс Fluent UI.
- **Полнофункциональный поиск Steam Store**: парсинг игр по названию или AppID, загрузка обложек, актуальных цен и списков дополнений в реальном времени.
- **Парсинг цен по регионам**: мониторинг стоимости тайтлов в RUB (Россия), KZT (Казахстан), USD (Турция/CIS, США) и UAH (Украина).
- **Генерация AppManifest (.acf)**: создание валидных файлов appmanifest_<appid>.acf в steamapps/ для мгновенной регистрации игр как установленных.
- **Экспорт конфигураций эмуляторов**: генерация smokeapi.json для локального перехвата дополнений рядом с исполняемыми файлами.
- **Управление манифестами .lua**: быстрое включение/отключение (.disabled) и физическое удаление файлов с диска.
- **Резервное копирование**: создание ZIP-архивов директории stplug-in в один клик.
